# projeto-do-meu-jogo-de-corrida
# 🏃 CORRIDA F-E-K

Jogo de corrida estilo quase Subway Surfers / Temple Run.

## Como começar

1. Abra o **index.html** no navegador
2. Pressione **ESPAÇO** ou qualquer **SETA**
3. Ou clique na estrada

## Controles

- ⬆️ Frente
- ⬇️ Trás
- ⬅️ Esquerda
- ➡️ Direita
- **P** ou **ESC** → Pausar

## O que tem

- Personagem animado (braços e pernas se mexem)
- Estrada de 3 faixas
- Obstáculos coloridos
- Sons (início, ponto, batida, pausa)
- Pontuação e velocidade

Boa sorte no projeto!
