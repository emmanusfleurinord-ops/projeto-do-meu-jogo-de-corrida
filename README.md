# projeto-do-meu-jogo-de-corrida
# 🏃 CORRIDA F-E-K

Jogo de corrida estilo quase Subway Surfers / Temple Run  
feito com HTML, CSS e JavaScript.

## Nome do jogo
**CORRIDA F-E-K**

## Como jogar

1. Abra o arquivo **index.html** no navegador
2. Pressione **ESPAÇO** para começar
3. Controles:
   - ⬆️ **Frente** → Corre para frente
   - ⬇️ **Trás** → Anda para trás
   - ⬅️ **Esquerda** → Muda para a esquerda
   - ➡️ **Direita** → Muda para a direita
   - **P** ou **ESC** → Pausar / Continuar o jogo

## O que tem no jogo

- Homem com cor verde-água (#00d2d3)
- Vários tipos de obstáculos (carros de cores diferentes)
- Sons (início, ponto, batida e pausa)
- Estrada de 3 faixas
- Pontuação e velocidade aumentando

## Arquivos do projeto

- `index.html` → Estrutura da página
- `style.css` → Visual e cores
- `script.js` → Toda a lógica do jogo + sons
- `README.md` → Este arquivo

## Dicas

- Use a seta para frente para correr mais rápido
- Use P ou ESC se precisar pausar
- Fique atento nos obstáculos coloridos!

Bom jogo e boa sorte no seu projeto! 🎮
